# 崩溃、非法访存与 core 定位

保留首个异常、退出信号、全部 rank 的邻近日志、失败请求和可信 dump、真实加载二进制/源码/编译配置。异步错误可能在后续同步点报告，最后栈帧不必然是出错 kernel；设备错误后继续执行的二次报错单独标注。

区分 host 异常/段错误、OOM/外部终止、GPU assert/非法访存和设备/链路故障。依据现场 DTK 的可用调试器、日志与 dump 支持选工具，先查匹配版本帮助；不将 cuda-gdb 或 CUDA 专用环境变量当 HCU 默认能力。

在隔离同版本目标重放，必要时缩小到首个可疑调用。保留真实 shape/dtype/stride、索引/page table、mask、alias、scale、路由和 stream，核越界、尾 tile、空输入、释放后使用、写读竞争及 graph 静态地址。同步诊断可能改变时序，只用于定位，修复须在原异步形态回归。

内核/库修改在任务副本进行，核实际加载新制品；局部原失败输入与边界回归后返回模型完整请求、graph/eager、并发和相关 rank 验证。若归因于硬件/驱动，带首错与设备身份交现场负责人，不自行重置共享节点。保存最小复现、修复 diff、构建哈希、回退制品和未覆盖条件。
