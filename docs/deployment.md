# 环境检查与部署

核对节点、设备身份、占用、授权资源、容器映射、DTK/驱动、PyTorch/引擎/HCU 插件和加载库。
设备空闲不等于授权，使用 admission 契约保留逐设备观测。性能预期来自相同条件历史或硬件/库来源，未知条件单列。

模型、tokenizer、revision、权重格式、激活/权重/KV 精度、chat template 与必需 API 功能要固定。
优先复现本地 cookbook 与当前 HCU 实现的适用配方，再核对官方语义；实际框架 CLI 需在选定版本查 help/源码。
预算权重、KV cache、工作区、graph 和峰值余量；按真实 workload 校准，不把降低模型尺寸的代理结果代表原模型。

部署产物：源码快照、显式命令卡、有效环境、启动及 readiness 原件、固定请求和质量结果、无 profiler baseline。
不要清理或重启其他服务。只管理任务创建且核验身份的进程；共享依赖在隔离工作树/安装前缀构建。
设备健康、链路或性能明显异常时核对单位、消息规模、映射、实际库和实现，保留已排除原因并转交现场负责人。
